# AetherFrame custom Dalamud repository

This branch is generated. It holds only `pluginmaster.json`, the file Dalamud reads as AetherFrame's custom plugin repository, and this README.

Please don't edit, rebase or force-push it. Every commit here is made by the **Publish custom repository** workflow of this repository, after it has verified the GitHub Releases the file points at. Each commit message records what was published, from which releases, and by which workflow run.

How the repository works, how to add it to Dalamud, and how releases reach it: [docs/CustomRepository.md](https://github.com/QuietFoxLabs/AetherFrame/blob/master/docs/CustomRepository.md) on `master`.
